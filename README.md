# Pinnacles for Claude Code

A Claude Code plugin with one skill, `apply-recommendations`: the procedure for applying Pinnacles SEO recommendations in your own repository and reporting back what you applied. It adds no tools of its own.

## Install

```
claude plugin marketplace add pinnacles-ai/skills && claude plugin install pinnacles@pinnacles
```

It needs a Pinnacles MCP connection, created in Settings in your Pinnacles dashboard. See https://pinnacles.ai/docs/mcp.

Maintained in the Pinnacles product repository and published here as a mirror; changes land there first.
